## Venture textures

The shipped plates are 1024×2304 WebP. `npm run optimize:textures` runs `scripts/optimize-textures.mjs` with dev-only `sharp`. It resizes the 1600×3600 PNGs, encodes WebP at quality 82 (stepping down only if the six files would pass 500 KB), and names each file with the first 8 hex characters of the SHA-256 of its bytes. The script rewrites `src/data/ventureTextures.ts` and deletes the PNGs from `public/` so they are not in the bundle. The PNGs remain in git history. Restore one with `git show <commit>:public/textures/ventures/<slug>.png`, then rerun the script.

Act 3 and the Act 4 target cards request those URLs only when scroll progress is within 0.1 of Act 3's start (`VENTURE_TEXTURE_LOAD_AT`). Until a plate arrives, the slab is that file's average color, then the image fades in over `duration.ui`. Reduced motion shows the plate as soon as it has uploaded. The texture uses `SRGBColorSpace`, mipmaps when the context is WebGL2, anisotropy capped at 4, and `gl.initTexture` immediately after load. The visible crop is unchanged: 1024×2304 and 1600×3600 are both 4:9.

`next.config.ts` `headers()` sets `Cache-Control: public, max-age=31536000, immutable` on `/textures/:path*` and `/images/:path*`. Hashed filenames make that cache safe. `/portrait/saeed.png` is not in the list. That path is fixed, and an immutable year cache would pin the first response, including a miss before the file exists. Do not set `output` in `next.config.ts`. The deploy build inserts `output: 'standalone'` itself.

Level-0 GPU memory for one plate is width × height × 4. Six 1600×3600 plates with mipmaps off were 138,240,000 bytes. Six 1024×2304 plates are 56,623,104 bytes at level 0 and 75,497,448 bytes with the mip chain.

## Motion

Scroll and the camera share one clock, then the picture eases on top of it.

- **Tokens.** `src/lib/motion.ts` is the duration, easing, and spring set (`micro` 0.18s, `ui` 0.32s, `reveal` 0.6s, `scene` 1.1s). `globals.css` exposes the same values as `--dur-*` and `--ease-*`. HUD color changes, overlay fades, and the Act frame use those tokens. Reduced motion collapses the CSS durations.
- **Smoothed clock.** Lenis (`lerp` 0.1) writes `scrollProgress.current` from its own `scroll` event. `CameraRig` advances `scrollProgress.smoothed` every WebGL frame with `THREE.MathUtils.damp` (lambda 7, delta capped at 1/30). That callback uses frame priority `-1` so it runs before the acts and the canvas still renders itself. The camera and the five scene acts read `smoothed`. `__oneCommandSeek` and an immediate `scrollToAct` copy `current` into `smoothed` on the same turn. When reduced motion is on, `smoothed` stays equal to `current`.
- **Camera curves.** `cinema.ts` bakes the approved camera into one centripetal `CatmullRomCurve3` per act segment. Hold segments are sampled so every approved knot is hit exactly, including progress `0`, `0.1`, `0.3`, `0.5`, `0.7`, `0.9`, and `1`. Glide segments ease scroll time with the cinematic quint and sample the curve at that eased time. Field of view and roll use the same blend. Reduced motion keeps the unsmoothed reference pose, no roll, and a fixed field of view.
- **Act handoff.** The cuts are `ACT_BOUNDARY_INTERNAL` in `cinema.ts` (internal 4.8, 9.9, 17.6, 23.5). `actHandoff` is a pure function of `scrollProgress.smoothed`. `pulse` is 0 outside a `duration.scene` window (1.1s of the show) and 1 on the cut. Outgoing overlays can only dim. An incoming overlay eases in early only when that copy is on screen by the end of the window, and it blurs with the cinematic quint. Key, hemisphere, fog, and the arena rig return to the approved values the moment the window closes. Depth of field is a DOM vignette. The high tier adds a 2.2px backdrop blur. There is no postprocessing pass, so Act 4 stays at 145 draw calls and Act 5 at 127.
- **Performance tier.** High caps device pixel ratio at 2, medium at 1.5, low at 1.25. Ship-burst sparks are 36, 18, and 10. The starfield stays at 2600 points so the hold frames match. A coarse pointer or a narrow viewport takes the lower budget, and pointer follow stays off. `PerformanceMonitor` can mark the session degraded, drop the burst to 8 sparks, and skip the depth veil.
- **Reduced motion.** The listener is live. Lenis turns `smoothWheel` off and sets `lerp` to 1, so the wheel is native. The handoff window shrinks to `duration.micro` and becomes an opacity fade with no blur and no light lerp. Magnetic, tilt, and split reveals stay off. Robot idle clocks stay at rest.
